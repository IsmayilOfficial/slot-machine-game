# Lucky Slots 🎰

A colorful casino-style slot machine built with React and Vite. The player starts with 1,000 coins, pays 10 coins per spin, and can win by matching two or three reel symbols.

## Features

- Three animated slot reels
- Four symbols: cherry, lemon, bell, and 7
- Starting balance of 1,000 coins
- 10-coin cost per spin
- 20 coins for two matching symbols
- 100 coins for three matching symbols
- Animated reel spinning
- Animated winner highlights
- Automatic spin-button disabling when coins are insufficient
- Responsive casino-style interface
- Beginner-friendly React code
